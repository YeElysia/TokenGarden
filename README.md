# TokenGarden

公开的个人 AI 用量花园。Next.js 展示端与服务端放在同一个仓库，`collector/` 包含 CC Switch 与 DSH 同步程序，`plugins/dsh-token-stats/` 是可维护的 DSH 统计插件重写版。

## 本地运行

需要 Node.js 22.13 或更新版本。

```sh
npm ci
npm run dev
```

访问 http://127.0.0.1:3000 。未配置数据库时展示明确标注的模拟数据，不会读取本机 CC Switch 或冒充真实使用量。

## 部署到 Vercel

1. 将此仓库导入 Vercel，选择 Next.js。
2. 创建托管 Postgres（例如 Neon），在 SQL 控制台执行 `db/schema.sql`。已有旧表也执行同一份 SQL：保留原数据、默认归入 CCS，增加渠道主键和快照版本表。若原数据实际包含 DSH，应先核对来源。
3. 在 Vercel 设置 `DATABASE_URL`，使用服务商提供的连接串；启用连接串要求的 TLS。
4. 配置独立的 `CCS_UPLOAD_TOKEN`、`DSH_UPLOAD_TOKEN`。如查询账户只读，另配有写入权限的 `UPLOAD_DATABASE_URL`；未配置时上传使用 `DATABASE_URL`。
5. 重新部署。数据库为空时显示真实的空状态，不回退到模拟用量。未配置 token 的上传通道会关闭。

首页及 `/api/stats` 完全公开，无登录。设备名、模型及用量会公开，请只写入你愿意公开的设备别名。数据库凭证仅供服务端使用，查询可使用只有 SELECT 权限的数据库账号。上传连接需要 usage_daily 的 SELECT/INSERT/UPDATE 权限、usage_uploads 的 SELECT/INSERT/UPDATE 权限及 replace_usage_snapshot 函数的执行权限；也可以先使用 Neon 创建的项目数据库账户。

## 当前范围

- 年度热力图、按日悬停/键盘焦点详情、年度选择。热力图按当前筛选结果中非零日期的用量分位数着色，不展示图例。
- 年份、设备、客户端、模型使用统一下拉菜单，支持方向键选择、Esc 关闭；无搜索框。摘要、模型占比与月度趋势同步更新。模型分布默认展示五行，可滚动查看其余模型。
- 站点按北京时间解释日期；总 token 为输入加输出，缓存输入作为输入子集展示。采集端日期沿用本地日历天，详见 collector/README.md。
- 公共查询 API；数据库故障返回错误，不伪造演示数据。
- CCS / DSH 分别鉴权上传：同一日期、渠道、设备、客户端、模型内，仅接受总 token 更高的累计记录；token 分类计数相同时允许补全或提高请求次数，缺席模型和空上传不会删除旧记录。两个渠道与不同设备相加，支持幂等重试和事务回滚。
- DSH 插件重写版支持日志调用次数、失败尝试、压缩与标题调用，以及旧统计迁移；详见 [插件说明](plugins/dsh-token-stats/README.md)。
- CC Switch 只读数据库采集（请求明细与归档汇总）及 DSH 统计文件上传，支持预览、跳过未变化日期和持续同步。
- 页面不提供刷新按钮或定时刷新，上传后可通过浏览器刷新查看。公开查询带 CDN 缓存，更新可能稍有延迟。

数据库只存每日汇总与上传版本，禁止写入密钥、对话、原始文件路径。采集端在各自渠道内完成去重后上传累计量，服务端按渠道独立保留各模型最高累计量并直接相加。上传协议、CCS / DSH 命令及同步状态说明见 `collector/README.md`。

## 配色

仅保留武陵素白与武陵夜航两款配色。按浏览设备的当地时间自动切换：07:00–19:00 使用素白，其他时间使用夜航；保持页面打开也会自动切换，不提供手动入口。统计日期仍按北京时间计算。

背景等高线为原创 SVG 装饰，不代表实际地形或官方地图。
