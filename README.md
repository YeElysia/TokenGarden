# TokenGarden

公开的个人 AI 用量花园。Next.js 展示端与服务端放在同一个仓库，`collector/` 预留给后续 CC Switch 同步程序。

## 本地运行

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run dev
```

访问 http://127.0.0.1:3000 。未配置数据库时展示明确标注的模拟数据，不会读取本机 CC Switch 或冒充真实使用量。

## 部署到 Vercel

1. 将此仓库导入 Vercel，选择 Next.js。
2. 创建托管 Postgres（例如 Neon），在 SQL 控制台执行 `db/schema.sql`。
3. 在 Vercel 设置 `DATABASE_URL`，使用服务商提供的连接串；启用连接串要求的 TLS。
4. 重新部署。数据库为空时显示真实的空状态，不回退到模拟用量。

首页及 `/api/stats` 完全公开，无登录。设备名、模型及用量会公开，请只写入你愿意公开的设备别名。数据库凭证仅供服务端使用，生产环境建议提供只有 SELECT 权限的数据库账号。

## 当前范围

- 年度热力图、按日悬停/键盘焦点详情、年度选择。
- 设备、客户端、模型筛选，摘要、模型占比与月度趋势同步更新。
- 北京时间；总 token 为输入加输出；缓存输入作为输入子集展示。
- 公共查询 API；数据库故障返回错误，不伪造演示数据。
- 尚未实现采集端、上传接口、真实数据去重和定时刷新；接入数据后刷新页面即可更新。

数据库是展示用的每日汇总投影，禁止写入密钥、对话、原始文件路径。后续采集端负责将不同客户端用量转换为统一口径、去重，再写入此投影；上传接口必须鉴权，与公开查询接口分开。

## 配色

仅保留武陵素白与武陵夜航两款配色。按浏览设备的当地时间自动切换：07:00–19:00 使用素白，其他时间使用夜航；保持页面打开也会自动切换，不提供手动入口。统计日期仍按北京时间计算。

背景等高线为原创 SVG 装饰，不代表实际地形或官方地图。
